## 2. Game Rules & Core Logic

### 2.1 Definitions

- **Tube:** holds at most `capacity` units of liquid (default 4).
- **Unit:** one colored layer, represented by an integer `0..N-1` (an index into the color palette).
- A tube is stored **bottom to top**: `[bottom, ..., top]`. The last element of the list is the top layer.

### 2.2 Pouring Rules

Pouring from tube `A` into tube `B` is allowed when **all** of the following are true:

1. `A != B`.
2. `A` is not empty.
3. `B` is not full (`B.length < capacity`).
4. `B` is empty **or** the top color of `B` equals the top color of `A`.

**Number of units poured:** `min(length of the same-color run at the top of A, capacity - B.length)`.
(In other words: pour the whole contiguous block of the same color until `B` is full.)

### 2.3 Win Condition

Every tube is either **empty** or **full with a single color**.

> Design assumption: every color has exactly `capacity` units. If you later want variable amounts per color, change the win condition to "each color sits entirely inside exactly one tube".

### 2.4 Stuck Condition

There is no valid move left (excluding pointless moves). When stuck, show options: "Undo / Add tube / Restart".

## 4. Rules for Staying 100% Offline

1. **No network packages:** no `http`, `dio`, Firebase, AdMob, or `google_fonts` (it downloads fonts at runtime).
2. **Bundle fonts** in `assets/fonts/` and declare them in `pubspec.yaml`.
3. **Ship levels** as a JSON file in `assets/levels/` (or generate them at runtime with Dart — see section 9).
4. **Audio and images** live in `assets/`, never loaded from URLs.
5. **Player data** is stored locally with `shared_preferences`.
6. **Do not declare the `INTERNET` permission** in the release `AndroidManifest.xml` (Flutter adds it automatically only for debug/profile builds for hot reload).
7. Testing: turn on **airplane mode** and run the whole gameplay flow to confirm.

> **Approved exception (2026-11-06):** `audioplayers` — the audio package chosen in §5 — declares `http` as a *transitive* dependency in every 1.x–6.x release (it backs `UrlSource`). No version in the current major line avoids it, and a replacement package would fall outside §5. The exception is allowed **only** because: (a) the app uses `AssetSource` exclusively, (b) no `INTERNET` permission is declared in the release manifest, so the app cannot open a network socket, and (c) the whole gameplay flow is re-verified in airplane mode before release (§19.4, §22.5). Adding `http`, `dio`, or any other network package as a **direct** dependency remains forbidden, and `flutter pub deps --no-dev` must be re-checked whenever dependencies change.

## 8. Pure Game Logic (Pure Dart)

File: `lib/domain/game_rules.dart`

```dart
import 'dart:math';
import 'models/move.dart';

/// Number of consecutive same-color units at the top of a tube.
int topRun(List<int> tube) {
  if (tube.isEmpty) return 0;
  var n = 1;
  while (n < tube.length && tube[tube.length - 1 - n] == tube.last) {
    n++;
  }
  return n;
}

bool canPour(Tubes t, int from, int to, int capacity) {
  if (from == to) return false;
  final src = t[from];
  final dst = t[to];
  if (src.isEmpty) return false;
  if (dst.length >= capacity) return false;
  if (dst.isNotEmpty && dst.last != src.last) return false;
  return true;
}

int pourCount(Tubes t, int from, int to, int capacity) =>
    min(topRun(t[from]), capacity - t[to].length);

/// Returns a NEW state (the old state is never mutated).
Tubes applyMove(Tubes t, Move m) {
  final next = [for (final x in t) List<int>.of(x)];
  final color = next[m.from].last;
  for (var i = 0; i < m.count; i++) {
    next[m.from].removeLast();
    next[m.to].add(color);
  }
  return next;
}

/// Reverts a move (used by Undo).
Tubes undoMove(Tubes t, Move m) {
  final next = [for (final x in t) List<int>.of(x)];
  final color = next[m.to].last;
  for (var i = 0; i < m.count; i++) {
    next[m.to].removeLast();
    next[m.from].add(color);
  }
  return next;
}

bool isTubeComplete(List<int> tube, int capacity) =>
    tube.length == capacity && tube.every((c) => c == tube.first);

bool isWon(Tubes t, int capacity) =>
    t.every((tube) => tube.isEmpty || isTubeComplete(tube, capacity));

/// All legal moves, with pointless ones filtered out:
///  - A completed source tube (full, single color) is never poured out.
///  - A single-color source into an empty target only relocates the liquid.
List<Move> legalMoves(Tubes t, int capacity) {
  final moves = <Move>[];
  for (var i = 0; i < t.length; i++) {
    final src = t[i];
    if (src.isEmpty) continue;
    if (isTubeComplete(src, capacity)) continue;
    final srcIsUniform = src.every((c) => c == src.first);
    for (var j = 0; j < t.length; j++) {
      if (!canPour(t, i, j, capacity)) continue;
      if (srcIsUniform && t[j].isEmpty) continue;
      moves.add(Move(i, j, pourCount(t, i, j, capacity)));
    }
  }
  return moves;
}

bool hasAnyMove(Tubes t, int capacity) => legalMoves(t, capacity).isNotEmpty;
```

**Key points:**

- Every function is **pure** (no side effects) → easy to test, easy to undo.
- `applyMove` always copies the state; with small boards (≤ 16 tubes × 4–5 layers) the cost is negligible.

## 9. Level System

### 9.1 Difficulty Parameters

| Levels | Colors | Empty tubes | Capacity | Total tubes | Notes |
|---|---|---|---|---|---|
| 1–6 | 3 | 2 | 4 | 5 | Tutorial-level basics |
| 7–12 | 4 | 2 | 4 | 6 | |
| 13–24 | 5–6 | 2 | 4 | 7–8 | |
| 25–48 | 7–8 | 2 | 4 | 9–10 | |
| 49–80 | 9–10 | 2 | 4 | 11–12 | |
| 81–120 | 11–12 | 2 | 4 | 13–14 | |
| 121+ | 8–12 | 2 | 5 | 10–14 | Capacity 5 |

Suggested formula: `colors = min(3 + (level - 1) ~/ 6, 12)`, `empty = 2`, `capacity = 4`.

### 9.2 Level Delivery Strategy (recommended: **pre-generate with a script and bundle in assets**)

**Why pre-generate?**

- No CPU cost at play time, no stutter when entering a level.
- 100% solvable (verified by the solver).
- The `par` (reference move count) is precomputed for star scoring.
- Fully offline because levels ship inside the app as a JSON file.

**Workflow:**

1. Write `tool/generate_levels.dart` using `LevelGenerator` + `Solver` from the Domain layer.
2. Run `dart run tool/generate_levels.dart` → writes `assets/levels/levels.json`.
3. Commit the JSON file to the repo.

### 9.3 Level Generation Algorithm

**Approach A (recommended): random shuffle + solver verification.**

```dart
// lib/domain/level_generator.dart
import 'dart:math';
import 'game_rules.dart';
import 'solver.dart';
import 'models/move.dart';

class LevelGenerator {
  /// Returns (tubes, par) or null if all attempts fail.
  static ({Tubes tubes, int par})? generate({
    required int colors,
    required int capacity,
    required int emptyTubes,
    required Random rng,
    int maxAttempts = 200,
    int solverNodeLimit = 300000,
  }) {
    for (var attempt = 0; attempt < maxAttempts; attempt++) {
      final units = <int>[
        for (var c = 0; c < colors; c++) ...List.filled(capacity, c),
      ]..shuffle(rng);

      final tubes = <List<int>>[
        for (var i = 0; i < colors; i++)
          units.sublist(i * capacity, (i + 1) * capacity),
        for (var i = 0; i < emptyTubes; i++) <int>[],
      ];

      // Reject levels that already contain a finished tube (too easy).
      if (tubes.any((t) => isTubeComplete(t, capacity))) continue;

      final solution = Solver.solve(tubes, capacity, maxNodes: solverNodeLimit);
      if (solution != null) {
        return (tubes: tubes, par: solution.length);
      }
    }
    return null;
  }
}
```

**Approach B (optional): reverse generation from a solved state.**
Start from the solved state and apply many random "reverse moves". Advantage: always solvable, no solver needed to verify. Drawback: every reverse move must correspond to a valid forward move (a forward pour requires the target's top color to match or the target to be empty), so the implementation is trickier. Approach A is recommended for simplicity and certainty.

### 9.4 Generation Script

```dart
// tool/generate_levels.dart
import 'dart:convert';
import 'dart:io';
import 'dart:math';
import 'package:up_water_sort/domain/level_generator.dart';

void main(List<String> args) {
  const totalLevels = 120;
  final rng = Random(2024); // fixed seed → reproducible output
  final levels = <Map<String, dynamic>>[];

  for (var id = 1; id <= totalLevels; id++) {
    final colors = min(3 + (id - 1) ~/ 6, 12);
    const capacity = 4;
    const empty = 2;

    final result = LevelGenerator.generate(
      colors: colors,
      capacity: capacity,
      emptyTubes: empty,
      rng: rng,
    );
    if (result == null) {
      stderr.writeln('Could not generate level $id, try raising maxAttempts.');
      exit(1);
    }
    levels.add({
      'id': id,
      'capacity': capacity,
      'colors': colors,
      'tubes': result.tubes,
      'par': result.par,
    });
    stdout.writeln('Level $id OK (colors=$colors, par=${result.par})');
  }

  File('assets/levels/levels.json').writeAsStringSync(
    const JsonEncoder.withIndent('  ').convert({'version': 1, 'levels': levels}),
  );
}
```

### 9.5 Loading Levels at Runtime

```dart
// lib/data/level_repository.dart
import 'dart:convert';
import 'package:flutter/services.dart' show rootBundle;
import '../domain/models/level_data.dart';

class LevelRepository {
  late final List<LevelData> _levels;

  Future<void> load() async {
    final raw = await rootBundle.loadString('assets/levels/levels.json');
    final json = jsonDecode(raw) as Map<String, dynamic>;
    _levels = (json['levels'] as List)
        .map((e) => LevelData.fromJson(Map<String, dynamic>.from(e)))
        .toList();
  }

  int get count => _levels.length;
  LevelData byId(int id) => _levels.firstWhere((l) => l.id == id);
  bool hasNext(int id) => id < _levels.length;
}
```

## 10. Solver, Hints & "Par" Calculation

### 10.1 Idea

- This is a state-space search problem. Use **BFS** (finds the shortest solution) with a node limit.
- **Canonicalize states** to avoid duplicates: tubes are interchangeable, so sort the list of tube strings and join them into a key.

### 10.2 Code

```dart
// lib/domain/solver.dart
import 'game_rules.dart';
import 'models/move.dart';

class _Node {
  final Tubes state;
  final int parent;
  final Move? move;
  _Node(this.state, this.parent, this.move);
}

class Solver {
  /// Canonical key: tubes are interchangeable, so sort before joining.
  static String key(Tubes t) {
    final parts = t.map((tube) => tube.join(',')).toList()..sort();
    return parts.join('|');
  }

  /// Returns the shortest list of moves, or null if none is found
  /// within [maxNodes].
  static List<Move>? solve(Tubes start, int capacity, {int maxNodes = 300000}) {
    final nodes = <_Node>[_Node(start, -1, null)];
    final seen = <String>{key(start)};
    var head = 0;

    while (head < nodes.length && nodes.length < maxNodes) {
      final node = nodes[head];
      if (isWon(node.state, capacity)) return _trace(nodes, head);

      for (final m in legalMoves(node.state, capacity)) {
        final next = applyMove(node.state, m);
        if (seen.add(key(next))) {
          nodes.add(_Node(next, head, m));
        }
      }
      head++;
    }
    return null;
  }

  static List<Move> _trace(List<_Node> nodes, int index) {
    final path = <Move>[];
    var i = index;
    while (nodes[i].parent != -1) {
      path.add(nodes[i].move!);
      i = nodes[i].parent;
    }
    return path.reversed.toList();
  }
}
```

### 10.3 Important Notes

- **Canonical keys are only for duplicate detection:** `key()` is never used to produce moves; each `Move` still uses the original tube indices of its node's `state`, so it stays valid.
- **BFS can use a lot of memory** on big levels (11–12 colors). Options:
  - Set `maxNodes` (e.g. 300,000) and treat exceeding it as "not solvable within the limit" → discard that level during generation.
  - Or add a **DFS with a visited set** that only checks solvability (not shortest), then set `par = DFS solution length × 0.7`.
- **In-game hint:** run `Solver.solve(currentTubes, ...)` inside `compute()` (an Isolate) and take `solution.first`. If it returns `null`, show "No hint found, try Undo."
- Run the solver on the **current state** (not the initial state), because the player may already be in a dead end.

### 11.2 `GameController` (skeleton)

```dart
enum GameStatus { playing, won, stuck }

class GameController extends ChangeNotifier {
  // ... dependencies

  late LevelData level;
  late Tubes tubes;
  int capacity = 4;
  int? selected;
  int moves = 0;
  bool busy = false;                 // locks input while animating
  bool extraTubeUsed = false;
  GameStatus status = GameStatus.playing;
  final List<Move> _history = [];

  bool get canUndo => _history.isNotEmpty && !busy;

  /// The UI assigns this callback to run the animation before state is committed.
  Future<void> Function(Move move, Tubes before)? playPourAnimation;

  void startLevel(LevelData data, {InProgress? resume}) {
    level = data;
    capacity = data.capacity;
    if (resume != null && resume.levelId == data.id) {
      tubes = [for (final t in resume.tubes) List.of(t)];
      _history..clear()..addAll(resume.history);
      moves = _history.length;
      extraTubeUsed = resume.extraTubeUsed;
    } else {
      tubes = [for (final t in data.tubes) List.of(t)];
      _history.clear();
      moves = 0;
      extraTubeUsed = false;
    }
    selected = null;
    busy = false;
    status = GameStatus.playing;
    notifyListeners();
  }

  Future<void> onTubeTap(int index) async {
    if (busy || status != GameStatus.playing) return;

    // 1. Nothing selected yet → select the source tube
    if (selected == null) {
      if (tubes[index].isEmpty) return;
      selected = index;
      audio.play(Sfx.select);
      notifyListeners();
      return;
    }

    // 2. Tap the selected tube again → deselect
    if (selected == index) {
      selected = null;
      notifyListeners();
      return;
    }

    final from = selected!;

    // 3. Invalid move
    if (!canPour(tubes, from, index, capacity)) {
      if (tubes[index].isNotEmpty) {
        selected = index;                // switch selection to the new tube
        audio.play(Sfx.select);
      } else {
        audio.play(Sfx.error);
        settings.haptic(HapticKind.error);
      }
      notifyListeners();
      return;
    }

    // 4. Valid move
    final move = Move(from, index, pourCount(tubes, from, index, capacity));
    busy = true;
    selected = null;
    notifyListeners();

    final before = tubes;
    await playPourAnimation?.call(move, before);   // wait for the animation

    tubes = applyMove(tubes, move);
    _history.add(move);
    moves++;
    busy = false;

    if (isTubeComplete(tubes[move.to], capacity)) {
      audio.play(Sfx.completeTube);
      settings.haptic(HapticKind.light);
    }

    if (isWon(tubes, capacity)) {
      status = GameStatus.won;
      await progress.completeLevel(level, moves);
      audio.play(Sfx.win);
    } else if (!hasAnyMove(tubes, capacity)) {
      status = GameStatus.stuck;
    }
    await _saveInProgress();
    notifyListeners();
  }

  void undo() {
    if (!canUndo) return;
    final m = _history.removeLast();
    tubes = undoMove(tubes, m);
    moves = _history.length;
    selected = null;
    status = GameStatus.playing;
    _saveInProgress();
    notifyListeners();
  }

  void restart() => startLevel(level);

  /// Adds one empty tube (once per level).
  bool addExtraTube() {
    if (extraTubeUsed || busy) return false;
    tubes = [...tubes, <int>[]];
    extraTubeUsed = true;
    status = GameStatus.playing;
    _saveInProgress();
    notifyListeners();
    return true;
  }
}
```

> **Undo after "Add tube":** the extra tube is always last in the list and is not part of `history`, so undo stays correct. The extra tube cannot be removed.

### 12.3 Tube Grid Layout

Layout rules:

- Total tubes `n ≤ 5`: one row.
- `n > 5`: two rows, `ceil(n / 2)` tubes per row.
- Tube size from `LayoutBuilder`:
  - `tubeWidth = min(maxWidth / perRow - gap, 64)`.
  - `tubeHeight = tubeWidth * (capacity * 0.9 + 0.6)` (suggested ratio; tune on a real device).
- Center the board and leave headroom above the tubes so a tube can **lift** when selected (offset ≈ `0.5 × tubeWidth`).

```dart
class TubesBoard extends StatelessWidget {
  const TubesBoard({super.key});

  @override
  Widget build(BuildContext context) {
    final game = context.watch<GameController>();
    final n = game.tubes.length;
    final perRow = n <= 5 ? n : (n / 2).ceil();

    return LayoutBuilder(builder: (context, c) {
      const gap = 12.0;
      final w = ((c.maxWidth - gap * (perRow + 1)) / perRow).clamp(36.0, 64.0);
      final h = w * (game.capacity * 0.9 + 0.6);

      final rows = <List<int>>[];
      for (var i = 0; i < n; i += perRow) {
        rows.add([for (var j = i; j < min(i + perRow, n); j++) j]);
      }

      return Column(
        mainAxisAlignment: MainAxisAlignment.center,
        children: [
          for (final row in rows)
            Padding(
              padding: const EdgeInsets.symmetric(vertical: 16),
              child: Row(
                mainAxisAlignment: MainAxisAlignment.center,
                children: [
                  for (final i in row)
                    Padding(
                      padding: const EdgeInsets.symmetric(horizontal: gap / 2),
                      child: TubeWidget(index: i, width: w, height: h),
                    ),
                ],
              ),
            ),
        ],
      );
    });
  }
}
```

## 13. Drawing Tubes with CustomPainter

```dart
// lib/ui/widgets/tube_painter.dart
import 'package:flutter/material.dart';
import '../../core/palette.dart';

class TubePainter extends CustomPainter {
  final List<int> layers;     // bottom -> top
  final int capacity;
  final bool selected;
  final bool colorBlind;
  final bool complete;

  TubePainter({
    required this.layers,
    required this.capacity,
    required this.selected,
    required this.colorBlind,
    required this.complete,
  });

  @override
  void paint(Canvas canvas, Size size) {
    final w = size.width;
    final h = size.height;
    final r = w / 2;

    // Tube outline: open at the top, rounded bottom.
    final tubePath = Path()
      ..moveTo(0, 0)
      ..lineTo(0, h - r)
      ..arcToPoint(Offset(w, h - r),
          radius: Radius.circular(r), clockwise: false)
      ..lineTo(w, 0);

    // Frosted glass background
    final glass = Path.from(tubePath)..close();
    canvas.drawPath(glass, Paint()..color = Colors.white.withOpacity(0.12));

    // Draw liquid layers, clipped to the tube shape
    canvas.save();
    canvas.clipPath(glass);

    final usableTop = h * 0.08;              // leave room at the rim
    final layerH = (h - usableTop) / capacity;

    for (var i = 0; i < layers.length; i++) {
      final top = h - (i + 1) * layerH;
      final rect = Rect.fromLTWH(0, top, w, layerH + 0.5); // +0.5 avoids hairline gaps
      canvas.drawRect(rect, Paint()..color = kPalette[layers[i]]);

      if (colorBlind) {
        final tp = TextPainter(
          text: TextSpan(
            text: kSymbols[layers[i]],
            style: TextStyle(
              color: Colors.white.withOpacity(0.9),
              fontSize: layerH * 0.55,
            ),
          ),
          textDirection: TextDirection.ltr,
        )..layout();
        tp.paint(canvas,
            Offset((w - tp.width) / 2, top + (layerH - tp.height) / 2));
      }
    }

    // Highlight streak on the left for a glassy look
    canvas.drawRect(
      Rect.fromLTWH(w * 0.12, 0, w * 0.1, h),
      Paint()..color = Colors.white.withOpacity(0.18),
    );
    canvas.restore();

    // Tube outline
    canvas.drawPath(
      tubePath,
      Paint()
        ..style = PaintingStyle.stroke
        ..strokeWidth = selected ? 3.5 : 2.5
        ..color = complete
            ? Colors.amber
            : (selected ? Colors.white : Colors.white70),
    );
  }

  @override
  bool shouldRepaint(TubePainter old) =>
      old.selected != selected ||
      old.capacity != capacity ||
      old.colorBlind != colorBlind ||
      old.complete != complete ||
      !_sameLayers(old.layers, layers);

  bool _sameLayers(List<int> a, List<int> b) {
    if (a.length != b.length) return false;
    for (var i = 0; i < a.length; i++) {
      if (a[i] != b[i]) return false;
    }
    return true;
  }
}
```

**TubeWidget:** wrap `CustomPaint` in a `GestureDetector(onTap: () => game.onTubeTap(index))`, use `AnimatedContainer`/`Transform.translate` to lift the tube when `selected`, and wrap it in a `RepaintBoundary` so other tubes are not repainted.

## 14. Pouring Animation

### 14.1 Two Implementation Levels

**Level 1 (simple, do first):** lift the source tube, wait briefly, update state, lower it. The target tube's liquid level rises with a `TweenAnimationBuilder`. Reliable and low-risk.

**Level 2 (polished, do later):** the source tube flies above the target tube, tilts, a liquid stream is drawn, the source level drops while the target level rises, then the tube returns.

### 14.2 Timeline of One Pour (≈ 900 ms)

| Phase | Duration | Action |
|---|---|---|
| 1. Travel | 250 ms | Source tube moves above the target tube (offset to the side) |
| 2. Tilt | 200 ms | Rotate ~ 60–75° |
| 3. Pour | 250–400 ms | Draw the stream; source level drops, target level rises linearly by `count` |
| 4. Return | 250 ms | Tube tilts back and returns to its original position |

### 14.3 How to Implement

1. `GameScreen` owns a `PourAnimator` (with an `AnimationController` + `TickerProvider`).
2. When `GameController.onTubeTap` calls `playPourAnimation(move, before)`, the `PourAnimator`:
   - Reads each tube's `GlobalKey` to find its on-screen position (`RenderBox.localToGlobal`).
   - Builds an `OverlayEntry` that draws the flying tube (above everything else) and **hides** the real source tube.
   - Runs `controller.forward()` and `await`s it, then removes the overlay.
3. During the animation, show a "fake" level for the target tube = `before[to].length + count * t` with `t` ∈ [0, 1].
4. After the animation completes, the controller commits `tubes = applyMove(...)`.

**Tips:**

- Use `Interval` to split one `AnimationController` into phases: `CurvedAnimation(parent: c, curve: Interval(0.0, 0.25, curve: Curves.easeOut))`.
- Keep `busy = true` while animating to block rapid taps.
- Small touches: a sparkle or golden outline when a tube is completed; confetti drawn with a `CustomPainter` when the level is won.

## 15. Local Persistence

### 15.1 `StorageService`

```dart
// lib/data/storage_service.dart
import 'dart:convert';
import 'package:shared_preferences/shared_preferences.dart';
import '../domain/models/save_data.dart';

class StorageService {
  static const _key = 'save_v1';
  final SharedPreferences _prefs;
  StorageService._(this._prefs);

  static Future<StorageService> create() async =>
      StorageService._(await SharedPreferences.getInstance());

  SaveData load() {
    final raw = _prefs.getString(_key);
    if (raw == null) return SaveData();
    try {
      return SaveData.fromJson(jsonDecode(raw) as Map<String, dynamic>);
    } catch (_) {
      return SaveData(); // corrupted data → start fresh, never crash
    }
  }

  Future<void> save(SaveData data) =>
      _prefs.setString(_key, jsonEncode(data.toJson()));

  Future<void> clear() => _prefs.remove(_key);
}
```

### 15.2 Principles

- **A single JSON key** (`save_v1`) makes migration easy: when the structure changes, read `version` and convert.
- **Write after every move** (small and fast) so quitting mid-game never loses progress.
- Wrap `jsonDecode` in `try/catch`; reset on corruption.
- Optionally debounce writes (e.g. 300 ms) if they turn out to be costly.

## 17. Stars, Scoring & Progression

### 17.1 Star Rating

Based on `par` (the estimated shortest move count from the solver):

| Condition | Stars |
|---|---|
| `moves ≤ par × 1.25` | ★★★ |
| `moves ≤ par × 1.75` | ★★ |
| Otherwise | ★ |

```dart
int starsFor(int moves, int par) {
  if (moves <= (par * 1.25).ceil()) return 3;
  if (moves <= (par * 1.75).ceil()) return 2;
  return 1;
}
```

### 17.2 Unlocking

- Completing level `N` → `unlockedLevel = max(unlockedLevel, N + 1)`.
- Stars are only saved if they are **higher** than the previous record.

### 17.3 `ProgressController.completeLevel`

```dart
Future<void> completeLevel(LevelData level, int moves) async {
  final s = starsFor(moves, level.par);
  final old = data.stars[level.id] ?? 0;
  if (s > old) data.stars[level.id] = s;
  if (level.id + 1 > data.unlockedLevel && levels.hasNext(level.id)) {
    data.unlockedLevel = level.id + 1;
  }
  data.inProgress = null;           // clear the saved game: it's finished
  await storage.save(data);
  notifyListeners();
}
```

## 18. Edge Cases

| # | Situation | Handling |
|---|---|---|
| 1 | Rapid taps while animating | `busy = true` → ignore taps |
| 2 | Tap an empty tube with nothing selected | Ignore |
| 3 | Tap the already-selected tube | Deselect |
| 4 | Select A, then tap a non-empty tube B that is an invalid target | Switch selection to B |
| 5 | Select A, then tap an invalid target that is empty/full | Haptic + error sound, keep A selected |
| 6 | No moves left | `status = stuck` → show Undo / Add tube / Restart |
| 7 | Undo while animating | Disable the button (`canUndo` checks `busy`) |
| 8 | App closed mid-game | Save `inProgress` after each move; on relaunch ask "Continue?" |
| 9 | Rotation / size changes | Lock to portrait; layout uses `LayoutBuilder`, so tablets still work |
| 10 | Corrupted save data | `try/catch` → reset to `SaveData()` |
| 11 | Ran out of bundled levels | Show a "Congratulations" screen + suggest Endless mode |
| 12 | Slow device, hint takes long | Run the solver in `compute()`, show a loader, cap `maxNodes` |
| 13 | App backgrounded mid-animation | Use `WidgetsBindingObserver`; on `paused`, cancel the animation and commit state immediately |
| 14 | "Add tube" used repeatedly | Limit to once per level (`extraTubeUsed`) |

## 20. Performance & Quality

- Wrap every tube in a `RepaintBoundary` so only changed tubes repaint.
- Make `shouldRepaint` precise (see section 13) to avoid redundant painting.
- Use `const` constructors wherever possible.
- Run Solver/Generator in an **Isolate** (`compute`) whenever they are called while the app is running.
- Avoid allocating new `Paint`/`TextPainter` objects on every `paint()` call where possible (optimize later, only if profiling shows a problem).
- Target: **60 fps** on mid-range devices; verify with Flutter DevTools (performance overlay).
- Keep the app small: compress audio (mp3/ogg at ~ 64–96 kbps), use WebP images.
- Enable strict lints (`flutter_lints`) and fix all warnings.

## 23. Risks & Mitigations

| Risk | Level | Mitigation |
|---|---|---|
| Solver is slow / memory-hungry on many-color levels | Medium | Cap `maxNodes`; generate levels offline with a script; run hints in an Isolate |
| Pouring animation is complex, with positioning bugs | Medium | Ship Level 1 first; keep Level 2 separate and behind a config flag |
| Levels too easy / too hard | Low | Playtest samples; tune the difficulty table (section 9.1); use fewer empty tubes at high levels |
| Save data lost after an app update | Low | `version` field + migration function; `try/catch` on read |
| Audio latency on some Android devices | Low | `PlayerMode.lowLatency`, short compressed files, preload |
| Colors hard to tell apart | Low | Symbol-based color-blind mode; verify the palette |
| A package silently requires network access | Low | Re-check `pubspec.yaml` (section 4); test in airplane mode |
